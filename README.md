# El camino de la hormiga

En el presente repositorio se encuentra el proyecto de la hormiga, un proyecto que combina interfas grefica de Qt con python haciendo uso del algoritmo BFS para poder encontrar por su propia cuenta
considerando que hay casillas que contienen alimento y bloqueos ademas, contara con una interaccion que permitira al usuario poder interactuar y mover a la hormiga entre las casillas
